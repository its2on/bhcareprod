IMPORTANT NOTES
================================================================================

1. PRIMARY KEYS:
   - AspNetUsers: Id (NVARCHAR(450) - GUID)
   - Most other tables: Id (INT IDENTITY)
   - Patients: UserId (NVARCHAR(450) - FK to AspNetUsers)

2. FOREIGN KEY PATTERNS:
   - ON DELETE NO ACTION: Prevents cascading deletes (most tables)
   - ON DELETE CASCADE: Deletes dependent records (some child tables)
   - ON DELETE SET NULL: Nullifies FK on parent delete (optional relations)

3. ENCRYPTED FIELDS:
   - Many NVARCHAR(MAX) fields support encrypted data
   - Requires IDataEncryptionService configuration
   - Fields marked with [Encrypted] attribute in models

4. COMPUTED COLUMNS:
   - AspNetUsers.FullName: Auto-computed from FirstName, MiddleName, LastName

5. INDEXES:
   - All primary keys auto-indexed
   - Foreign keys indexed for performance
   - Common query fields indexed (dates, status, etc.)

6. SESSION-BASED DATA:
   - OTP codes stored in HttpContext.Session (NOT in database)
   - Session expires after 5 minutes for security
