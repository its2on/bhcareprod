## 🧠 3. Standard Logging Implementation

Add this block after each important database action (`SaveChangesAsync()` or similar):

```csharp
await _auditTrail.LogAsync(
    "ActionType",          // Create, Update, Delete, View, Login, Logout
    "Action description",
    "EntityName",          // e.g., "Appointment", "User", "Prescription"
    entity.Id.ToString(),
    oldValuesJson,
    newValuesJson,
    "Optional detailed description"
);
```

**Implementation Notes:**
- Inject `IAuditTrailService` into each PageModel.
- Serialize objects using `JsonConvert.SerializeObject()`.
- Wrap in try/catch — never allow audit failure to break app execution.
