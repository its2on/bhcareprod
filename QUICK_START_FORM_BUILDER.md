# 🚀 Quick Start - Form Builder

## Get Started in 5 Minutes!

### Step 1: Access Form Management
Navigate to: `/Admin/FormManagement`

### Step 2: Create Your First Form
1. Click **"Add New Form"** button
2. Enter form details:
   - **Form Title:** "Patient Registration"
   - **Description:** "New patient information form"
   - **Category:** "Registration"
   - Form Key auto-generates

### Step 3: Add Questions

Click these buttons in the right sidebar:

1. **Short Answer** → "Full Name" → Toggle Required ✓
2. **Email** → "Email Address" → Toggle Required ✓
3. **Phone Number** → "Contact Number" → Toggle Required ✓
4. **Date** → "Date of Birth" → Toggle Required ✓
5. **Multiple Choice** → "Gender"
   - Add option: "Male"
   - Add option: "Female"
   - Add option: "Other"

### Step 4: Preview & Save
1. Click **"Preview"** to see your form
2. Click **"Save Form"** to store it

### Step 5: Share Your Form
Copy and share this URL:
```
/Forms/SubmitForm/patient-registration
```

### Step 6: View Responses
1. Go back to Form Management
2. Click the **chart icon** next to your form
3. See responses in real-time!

### Step 7: Export Data
In the Responses page:
- Click **"Export to CSV"** for Excel
- Click **"Export to JSON"** for API use

## 🎯 Common Tasks

### Create a Survey
1. Add form title: "Patient Satisfaction Survey"
2. Add Multiple Choice questions
3. Use 1-5 rating scale options
4. Save and share

### Create a Booking Form
1. Add form title: "Appointment Booking"
2. Add Date field → "Preferred Date"
3. Add Time field → "Preferred Time"
4. Add Dropdown → "Service Type"
5. Save and share

### View Analytics
1. Open Form Management
2. Click chart icon on any form
3. Switch to "Summary" tab
4. See pie charts and bar graphs

### Duplicate a Form
1. Find your form in the list
2. Click the **copy icon**
3. Edit the duplicate
4. Save as new form
