SQL Server Authentication Connection String for BH Care
========================================================

After running setup_sql_auth.sql, use this connection string:

Server=DESKTOP-NU53VS3\SQLEXPRESS;Database=Barangay;User Id=bhcare_app;Password=BHCare@2024!Secure;MultipleActiveResultSets=true;TrustServerCertificate=True;Encrypt=False;

Steps to Enable SQL Authentication:
====================================

1. Run setup_sql_auth.sql in SQL Server Management Studio
   - This creates login: bhcare_app
   - Password: BHCare@2024!Secure

2. Restart SQL Server (Run as Administrator in PowerShell):
   Restart-Service MSSQL$SQLEXPRESS

3. Update appsettings.json with the new connection string above

4. Test the connection
